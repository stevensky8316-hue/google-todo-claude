A．Gmail 自動掃描

第一次用：OAuth 設定
  1. 預設 Client ID 是「Google 待辦 Claude 版」那組，已授權來源 https://stevensky8316-hue.github.io。把本檔放在同一個 GitHub Pages 網域下就能直接用。
  2. 同一個 Cloud 專案要啟用 Gmail API（API 和服務 → 程式庫 → Gmail API → 啟用）。
  3. OAuth 同意畫面（測試中）：自己的 Gmail 要在測試使用者名單裡；可順手把 .../auth/gmail.readonly 加進範圍。
  4. 放在其他網址的話：在 OAuth 用戶端的「已授權的 JavaScript 來源」加上 （備案重新導向 URI：）。
  5. 不能直接雙擊用 file:// 開。
